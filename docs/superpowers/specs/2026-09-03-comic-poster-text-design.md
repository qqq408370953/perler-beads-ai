# 封面热血漫画艺术字设计

## 目标

在封面自由布局编辑器中增加“热血漫画”艺术字。文字继续保持可编辑，不转为固定图片；自由布局预览、页面预览和下载 PNG 必须使用同一套样式参数。

## 视觉组成

- 粗黑体和紧凑字距。
- 黄、橙、红逐字分段配色，每个字保留轻微明暗渐变。
- 超粗黑色外描边。
- 向右下方延伸的硬边立体厚度。
- 横向拉伸、纵向缩放和轻微错切。
- 单字有确定性的轻微高低、旋转和高度变化，不能每次渲染随机变化。

## 数据与交互

扩展现有文字样式，保存填充模式、三个颜色、横纵拉伸、错切角度、立体厚度与颜色、单字节奏强度。选择“热血漫画”时一次写入推荐值，之后用户可以继续精调。现有艺术字预设继续兼容。

“应用到全部文字”复制完整样式；未点击该按钮时只改变当前选中的文字。

## 渲染

- DOM 编辑器使用逐字 `span`、CSS 渐变、描边、多层硬阴影与二维变换。
- Canvas 预览和下载按字符绘制相同的配色与节奏，使用多次偏移绘制形成硬边立体厚度。
- 使用 1080×1440 设计坐标绘制，不先把文字栅格化后再放大。
- 对旧状态缺少的新字段提供默认值。

## 验证

- 单元测试验证预设值、逐字颜色与节奏的确定性、完整样式复制和旧样式默认值。
- 运行完整测试、TypeScript 检查、生产构建及 `git diff --check`。
