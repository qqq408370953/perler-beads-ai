# 封面处理页交互升级设计

## 目标

升级 `/poster` 封面处理页，在不改变默认自动排版体验的前提下，增加单图框选去水印、正确的文件名占位行为、全屏自由布局编辑和更多高质量封面配色。桌面端与移动端都需要可用，预览与导出结果必须一致。

## 当前实现

- 页面位于 `src/app/poster/page.tsx`，使用 1080×1440 Canvas 生成预览和导出图片。
- 自动布局根据图片数量选择固定网格，标题、图片和图片名称的位置由 Canvas 渲染函数直接计算。
- 工具页已有 `WatermarkRemovalModal` 和 `removeWatermarkRegion`，可复用框选、连续处理与本地修复算法。
- 图片标签状态当前为空，但未保存文件名作为每个输入框自己的占位文本。
- 背景预设只有起止颜色，没有名称与前景色策略。

## 方案选择

采用原生 DOM 图层编辑器与共享 Canvas 变换模型，不引入 Fabric.js、Konva 等第三方画布依赖。

全屏弹框负责可视化交互；所有位置、大小和旋转角度保存为基于 1080×1440 设计画布的归一化变换。预览 Canvas 和导出 Canvas 都读取同一份数据，因此不会出现编辑弹框中看到的位置与导出结果不一致。

## 单图框选去水印

1. 每个图片卡片增加“框选去水印”按钮。
2. 点击后使用该项当前原图打开现有 `WatermarkRemovalModal`。
3. 为弹框增加可选文案属性，使工具页继续显示“生成前手动去水印 / 完成并去裁剪”，封面页显示“封面图片去水印 / 完成并返回”。默认属性保持现有工具页行为，避免回归。
4. 完成后同时更新该项的 `originalSrc` 与 `processedSrc`，把状态重置为待处理。用户可以直接使用去水印图，也可以再次执行抠图、像素化和描边处理。
5. 关闭弹框不修改图片；处理中禁止重复提交或关闭。

## 文件名占位规则

每个 `PosterItem` 保存 `sourceName` 和 `label`：

- `sourceName`：上传文件去除扩展名后的名称，只用于输入框 `placeholder`、缩略图辅助说明和编辑器图层识别。
- `label`：用户输入的名称，初始值必须是空字符串。
- 用户不输入名称时，不把 `sourceName` 写入封面，也不参与 Canvas 渲染或导出。
- 用户开始输入后，`label` 立即替换输入框中显示的 placeholder，封面预览和自由布局弹框立即显示 `label`。
- 用户清空输入后，输入框重新显示文件名 placeholder，同时封面中的该名称消失。

## 自由布局数据模型

新增布局模式状态：

```ts
type PosterLayerKind = 'image' | 'item-label' | 'title' | 'subtitle' | 'bottom-title' | 'fixed-text';

interface PosterLayerTransform {
  id: string;
  kind: PosterLayerKind;
  x: number;
  y: number;
  scale: number;
  rotation: number;
  zIndex: number;
}
```

`x`、`y` 使用设计画布坐标；`scale` 相对于自动布局的基准尺寸；`rotation` 使用角度。图层 ID 稳定关联标题字段或图片 ID，图片增删后可以保留仍存在图层的自定义变换，并为新增图层生成自动位置。

当不存在自定义布局时，渲染函数沿用当前自动布局。首次打开自由布局时，根据当前图片数量、布局模式和已有文字生成一组基准图层。只有用户点击“应用布局”才写入正式自定义布局。

## 全屏自由布局编辑器

1. 页面增加“解锁自由布局”开关，默认关闭。
2. 打开开关时进入全屏弹框；关闭开关只结束可编辑状态，不清除已经应用的自定义布局。
3. 弹框中每个可见标题、字幕、底部文字、图片和已输入的图片名称都是独立图层。
4. 单击或轻触选择图层；拖动主体移动；角部控制点等比缩放；旋转柄调整角度。
5. 移动端支持单指拖动和双指缩放、旋转。手势开始后阻止页面滚动，未选中图层区域仍可正常操作工具栏。
6. 选中图层时显示当前缩放比例和旋转角度，并提供置顶、置底、上移一层、下移一层，解决自由重叠时的遮挡。
7. 所有图层限制在可恢复的画布安全范围内，不允许整个图层完全拖出画布；缩放设置合理上下限。
8. 底部固定操作包含“取消修改”“恢复自动布局”“应用布局”。取消恢复打开弹框前的状态；恢复自动布局需要二次确认；应用后关闭弹框并保留结果。
9. 键盘支持方向键微调，Shift + 方向键大步移动；Escape 在没有未保存修改时关闭，有修改时先确认。

## 渲染与导出

将当前直接写死位置的 Canvas 代码拆为两层：

1. `buildPosterLayers` 根据图片、文字、布局模式生成基准图层及其内容和尺寸。
2. `renderPosterCanvas` 根据基准图层叠加自定义变换，在每层绘制前执行 `translate`、`rotate`、`scale`。

自动布局路径的视觉结果保持不变。应用自定义布局后，页面预览、全屏编辑器和下载均使用同一套图层顺序与变换。图片继续关闭平滑插值以保持像素素材清晰；文字缩放基于设计尺寸绘制，避免先栅格化再放大造成模糊。

## 封面配色

把背景预设从二元数组改成带名称的对象，保留现有预设并新增至少 12 组经典组合：

- 藏蓝金：稳定、品质感
- 靛蓝薰衣草：专业、柔和
- 湖蓝珊瑚：互补、活力
- 薄荷奶油：清新、治愈
- 鼠尾草米白：自然、克制
- 陶土奶杏：温暖、手作感
- 酒红浅粉：精致、复古
- 深绿香槟：自然、高级
- 天空蓝柠檬黄：明快、年轻
- 紫罗兰蜜桃：创意、亲和
- 石墨蓝雾：现代、冷静
- 可可玫瑰：温柔、稳重

每个预设提供背景起止色以及建议的主文字、次文字颜色。点击预设时同步应用文字配色。用户使用自定义背景色时，根据背景相对亮度自动选择深色或浅色文字，保证可读性。色块按钮使用预设名称作为 `aria-label` 和 `title`。

## 组件边界

- `WatermarkRemovalModal.tsx`：只增加可选文案，不复制去水印逻辑。
- `PosterFreeLayoutModal.tsx`：负责图层选择、拖动、缩放、旋转、层级和手势交互。
- `posterLayout.ts`：纯函数，负责基准图层、变换约束、图层合并和背景对比色。
- `poster/page.tsx`：管理页面状态、图片 CRUD、打开弹框、预览和导出。

拆分后避免继续扩大现有 900 多行页面文件，也便于对坐标算法做单元测试。

## 错误与边界处理

- 去水印失败时保留原图并在弹框内显示错误。
- 图片加载失败时保留现有占位表现，不阻塞其它图层编辑。
- 图片被删除时同步移除其图片与名称图层。
- 文字为空时不渲染对应图层；再次输入时根据自动布局生成可编辑图层。
- 自定义布局异常或缺少图层时回退到自动布局，而不是阻止预览或导出。
- 屏幕尺寸变化只改变编辑器显示比例，不改变设计坐标和导出结果。
